# fOrge - Organization Defaults

This repository holds fOrge's public organization profile and the default files shared by every fOrge repository.

| Path | Purpose |
|---|---|
| `profile/README.md` | Public fOrge homepage at [github.com/forge-stud](https://github.com/forge-stud) |
| `CONTRIBUTING.md` | How we work: branches, commits, pull requests, reviews and approvals |
| `SECURITY.md` | How to report a security vulnerability |
| `CODE_OF_CONDUCT.md` | Expected behaviour for everyone working on fOrge |
| `PULL_REQUEST_TEMPLATE.md` | Default pull request description and checklist |
| `ISSUE_TEMPLATE/` | Default forms for bugs, features, tasks and milestone approvals |

Any fOrge repository without its own version of these files automatically uses the ones here.

## Important

**This repository is public.** Never add internal information, credentials, customer data or unreleased plans here. Internal content belongs in fOrge's private repositories.

Changes to this repository are made by the Platform-Admin team.
